# Домашнее задание к занятию "Самостоятельное задание к занятию «Установка ispmanager на Linux»" - Костенко Максим

**1. Установка ispmanager**

Подключитесь к серверу по SSH с правами суперпользователя.

Загрузите скрипт установки и запустите его :
```bash
# Скачать установщик
wget https://download.ispmanager.com/install.sh -O install.sh

# Выдать право на выполнение
chmod +x install.sh

# Запустить
./install.sh
```
Во время установки ответьте на вопросы:
- Ветка обновлений: выберите stable (стабильная версия) .
- Версия ispmanager: выберите lite, pro или host с рекомендуемым ПО. Для учебных задач обычно достаточно Lite .
- Веб-сервер: выберите Nginx + Apache (MPM-ITK) — вариант под цифрой, указанной в задании .
- СУБД для панели: выберите SQLite .

Дождитесь окончания установки (обычно 3–15 минут) .

> [!IMPORTANT]
> Если возникла ошибка AppArmor is enabled — отключите AppArmor и запустите установку заново :
```
bash
aa-teardown
systemctl stop apparmor
systemctl disable apparmor
```
> [!IMPORTANT]
> Если возникла ошибка You have incorrect hostname — запустите с ключом :
```bash
sh install.sh --ignore-hostname
```
**2. Вход в панель и активация лицензии**

Перейдите по адресу :
```text
https://IP-адрес-сервера:1500/ispmgr
```
Браузер выдаст предупреждение о незащищённом соединении — это нормально, так как используется самоподписанный сертификат. Примите исключение и продолжите .

Введите данные для входа:
- Логин: root
- Пароль: пароль от root на сервере 

Активация лицензии: если сервер имеет публичный статический IP, лицензия активируется автоматически при установке. Если нет — активируйте вручную по ключу через раздел «Управление лицензией» → «Активировать лицензию» .

**3. Базовая настройка панели**

После входа выполните первичную настройку:
- Имя сервера (hostname) — задайте корректное FQDN-имя.
- Часовой пояс — установите Europe/Moscow (или согласно заданию).
- Язык интерфейса — выберите русский.

Эти настройки находятся в разделе «Настройки» → «Настройки сервера» или в правом верхнем углу под именем пользователя.

**4. Создание учётной записи администратора с правами суперпользователя**

1. В левом меню нажмите «Все разделы».
2. Найдите «Администраторы» и нажмите на звёздочку рядом — раздел закрепится в меню.
3. Откройте раздел «Администраторы».
4. Нажмите «Создать администратора».
5. Заполните форму:
- Логин: например, admin
- Пароль: задайте надёжный пароль
- Уровень доступа: выберите «Суперпользователь» 
6. Сохраните.

**5. Создание обычной учётной записи администратора**

1. В разделе «Администраторы» снова нажмите «Создать администратора».
2. Заполните:
- Логин: например, admin2 (или как указано в задании)
- Пароль
- Уровень доступа — выберите «Администратор» (без прав суперпользователя) .
- Сохраните.

**6. Создание учётной записи пользователя**

1. В левом меню откройте раздел «Пользователи» (если его нет — добавьте через «Все разделы» → звёздочка).
2. Нажмите «Создать пользователя» .
3. Заполните форму:
- Логин: например, user
- Пароль
- Подтверждение: повторите пароль
- Имя: укажите имя пользователя
- Комментарий: при необходимости
- В блоке «Ограничения» укажите лимиты согласно заданию (например, диск, трафик, количество сайтов) .
- В блоке «Доступ» снимите галочки с функций, которые пользователю не положены (например, «Может использовать shell», «Может использовать SSL» и т. д.) .
- Сохраните.

**7. Настройка доступов и ограничений**

1. Зайдите в настройки созданного пользователя и ограничьте его права согласно заданию. Основные настройки находятся в разделах:
2. «Права» (или «Права на панели инструментов») — снимите галочки с лишних функций. Права для конкретной учётной записи имеют приоритет над групповыми .
3. «Лимиты» — ограничения на количество создаваемых объектов (сайтов, баз данных, почтовых ящиков) .
4. «Ресурсы» — лимиты на использование ресурсов сервера (только для ispmanager host) .
5. «Доступ» — разрешённое ПО: SSL, CGI, PHP, shell и т. д. .
6. Чтобы настроить доступ к функциям для пользователя :
- Перейдите в «Пользователи» → кнопка «Права на панели инструментов».
- Выберите функцию и нажмите «Включить» или «Выключить».

Для тонкой настройки: выберите функцию → «Права доступа» → снимите «Унаследовать» → выберите «Разрешить» или «Запретить» → нажмите «Сохранить».

**8. Проверка от лица пользователя**

1. Выйдите из панели под root.
2. Войдите под созданным пользователем user.
3. Убедитесь, что:
- Интерфейс урезан — нет лишних разделов (например, «Администраторы», «Настройки сервера»).
- Пользователь не может выполнять запрещённые действия (создавать сайты, заходить в раздел администраторов и т. п.).
